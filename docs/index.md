# Руководство по разработке

Руководство объединяет правила, по которым команда пишет код, тесты и документацию и организует работу над задачами. После прочтения вы сможете подготовить изменение так, чтобы оно прошло ревью без замечаний по стилю.

## Для кого это руководство

- разработчики: пишут код, тесты, описания изменений и ревью PR;
- тестировщики и аналитики: заводят задачи в YouTrack и пишут документацию;

## Как пользоваться

1. Прочитайте разделы «Общие принципы» и «Наименование»: на них опираются остальные.
2. Во время работы сверяйтесь с правилами. У каждого правила есть идентификатор (например, C-06), на него ссылаются в ревью.
3. Перед pull request пройдите критерии готовности из раздела «Процесс работы».
