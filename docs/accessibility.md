# Доступность документации

Раздел помогает писать документацию, которую смогут прочитать все.

## Альтернативный текст (A-01)

**Правило.** У каждого изображения есть альтернативный текст.

## Понятные ссылки (A-02)

**Правило.** Текст ссылки описывает цель перехода. Не пишите "здесь".

## Не только цвет (A-03)

**Правило.** Не опирайтесь на цвет как на единственный признак.

## Заголовки (A-04)

**Правило.** Заголовки идут по порядку.
