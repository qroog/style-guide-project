# Правила наименования

Раздел описывает, как называть идентификаторы, файлы, таблицы, ветки и переменные окружения.

## Имя отражает смысл (N-01)

**Правило.** Имя описывает назначение, а не реализацию. Не сокращайте слова, кроме общепринятых (`id`, `url`, `http`).

| Плохо | Хорошо |
|---|---|
| `usrLst`, `tmp2`, `data` | `activeUsers`, `parsedConfig`, `orderItems` |

## Язык (N-02)

**Правило.** Идентификаторы, имена файлов, таблиц, веток и коммитов — на английском. Комментарии и документация — на русском.

## Имена в Go (N-03)

**Правило.** Пакеты — короткие, строчные, одно слово, без подчёркиваний (`order`, а не `order_utils`). Экспортируемые идентификаторы — `PascalCase`, неэкспортируемые — `camelCase`. Аббревиатуры пишутся одним регистром: `ID`, `URL`, `HTTP`.

| Плохо | Хорошо |
|---|---|
| `get_task`, `userId`, `HttpClient` | `GetTask`, `userID`, `HTTPClient` |

## Интерфейсы (N-04)

**Правило.** Интерфейс с одним методом называется по методу с суффиксом «-er»: `Reader`, `Closer`. Префикс `I` не используется.

## Функции, типы и булевы значения (N-05)

**Правило.** Функции называются глаголом (`LoadConfig`), типы и переменные — существительным (`Config`). Булевы значения и функции-предикаты начинаются с `is`, `has` или `can`: `isActive`, `hasAccess`.

## Длина имени и область видимости (N-06)

**Правило.** Чем шире область видимости, тем информативнее имя. Короткие имена (`i`, `n`) допустимы только в маленьком блоке.

## Файлы (N-07)

**Правило.** Файлы Go — `snake_case` (`order_service.go`), тесты — с суффиксом `_test.go`. Файлы документации — `kebab-case` (`create-order.md`).

## Таблицы и столбцы SQL (N-08)

**Правило.** Таблицы — существительные во множественном числе в `snake_case` (`orders`). Столбцы — `snake_case` в единственном числе. Первичный ключ — `id`, внешний — `<таблица_в_ед_числе>_id` (`user_id`). Индексы — `idx_<таблица>_<столбцы>`, ограничения — `pk_`, `fk_`, `uq_`.

## Ветки Git (N-09)

**Правило.** Формат: `<тип>/<ключ-задачи>-<описание>`, например `feature/PROJ-123-add-login`. Типы: `feature`, `fix`, `docs`, `refactor`, `chore`.

## Константы и переменные окружения (N-10)

**Правило.** Константы Go — `MixedCaps` без `SCREAMING_CASE`. Переменные окружения — `UPPER_SNAKE_CASE` с префиксом сервиса: `ORDERS_DB_URL`.
